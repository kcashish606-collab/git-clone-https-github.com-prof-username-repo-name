# "The Paper Boat": complete video package

An original emotional animated short for a faceless channel, modeled on the *structure* of the reference film "Hair Love" (Sony Pictures Animation) but with its own characters and story.

| File | What it is |
|---|---|
| `analysis.md` | Breakdown of the reference: channel, story pattern, hooks, and more topic ideas |
| `script.md` | Full 5-minute narrated script with scene directions |
| `transcript.txt` | Narration only, for caption auto-sync and voiceover |
| `metadata.md` | Title + alternates, description with chapters, tags, settings, cards, pinned comment, community post |
| `shorts.md` | Two Shorts cut-downs |
| `thumbnails/thumbnail-1/2/3.png` | Three 1280×720 thumbnails for Test & Compare |
| `video/the-paper-boat-1080p.mp4` | **The finished 5:00 video**: 1920×1080, 2D animation, burned-in captions, **no voice yet** |
| `video/story.html` + `render.js` | Editable animation source; re-render with `node videos/04-paper-boat/video/render.js` |
| `seedance/clip-prompts.md` | 20 ready-to-run Seedance 2.0 clip prompts at 1080p, with locked style and a cost table |

## What's blocked and why
| Asked for | Status |

| Seedance 2.0 at 1080p | **Not possible on this account yet.** Needs the Plus plan or higher (1080p requires `mode: std`) and about **3,600 credits**. The balance is 1.7 credits on the free plan. All 20 clip prompts are ready in `seedance/clip-prompts.md`. |
| Voiceover | **Needs about 15 Higgsfield credits** (about 420 words with the Celine voice). The balance is 1.7. Once topped up, the 8 narration blocks can be generated and mixed in, and the scenes retimed to the voice the same way as the sleep Shorts. |
