# YouTube Upload Package — "What Happens to Your Body If You Stay Awake for 11 Days"

| File | What it's for |
|---|---|
| `../bright-side-style-script.md` | Full narration script with visual directions |
| `metadata.md` | Title, alternate titles, description with chapters, tags, settings, end screen, cards, pinned comment, community post, schedule |
| `thumbnails/thumbnail-A.png` / `-B.png` / `-C.png` | Three 1280×720 thumbnails for Test & Compare |
| `thumbnails/thumbnail-source.html` + `render.js` | Editable thumbnail source (original vector art) |
| `transcript.txt` | Narration only. Paste into Subtitles → Auto-sync for accurate captions |
| `shorts.md` | Two vertical Shorts cut-downs to promote the video |

- [ ] Facts double-checked against the sources in the description
- [ ] Chapter timestamps updated to the final edit
- [ ] Title + description + tags pasted from `metadata.md`
- [ ] Thumbnails A, B, C uploaded to Test & Compare
- [ ] Audience: not made for kids; category: Education
- [ ] Altered-content disclosure set correctly (AI voice or realistic AI visuals → Yes)
- [ ] Captions: auto-sync `transcript.txt`
- [ ] End screen + 3 cards added
- [ ] Scheduled (not public) and HD processing finished
- [ ] Community poll posted 24 h before
- [ ] Pinned comment posted right after going live
- [ ] Shorts scheduled for day +1 and day +3
- [ ] 48-hour check: CTR, AVD, 30-s retention (see `metadata.md` §11)
